# 수강생 발표 & 피드백 메모 보드

made by 유환일

수업 시간 개별 발표를 랜덤 순서로 진행하고, 학생들이 QR로 익명 메모·좋아요를 남기는 웹앱입니다.

- `index.html`: 화면 파일입니다. 학생 이름이나 메모는 들어 있지 않습니다.
- 데이터(수업, 명단, 진행 기록, 메모, 좋아요)는 교수자의 구글 시트에만 저장됩니다.
- `apps-script/Code.gs`: 구글 시트에 붙이는 데이터 서버 코드입니다. 관리키는 비워 두었습니다.

## 주소
- 학생용 보드: `…/?cls=수업id&view=board` (콘솔의 수업 카드에서 복사)
- 교수자 콘솔: `…/?console` (처음 한 번은 관리키를 입력하거나 `…/?admin=관리키`로 엽니다. 그 브라우저에서는 다음부터 `?console`만으로 열리고, 공용 컴퓨터에서는 콘솔의 「이 브라우저에서 로그아웃」을 누릅니다.)
- 미리보기: `…/?demo=1`

## 서버 주소를 바꿀 때
`index.html` 안의 `API_URL` 한 줄만 새 Apps Script 웹 앱 주소로 바꾸면 됩니다.
